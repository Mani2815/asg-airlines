# ASG Airlines — Streamlit Portfolio Demo

## Purpose
This application is an **Additional** interactive visualization and demonstration layer for the ASG Airlines Data Engineering project. It does not replace the official Power BI dashboards submitted as the core BI solution. It serves to showcase how the validated curated data can be dynamically explored using a Python web framework.

## Pages & Views
The application provides an interactive, tab-based navigation structure:
- **Overview:** High-level flight operations, KPI cards, airline volume, and booking status.
- **Route Analysis:** Drill-down into flight volume vs booking demand across individual routes.
- **Duration & Anomalies:** Distribution of flight duration and statistical anomaly analysis.
- **Airline Analysis:** Deep-dive into specific airlines, their original vs derived source mapping, and route distributions.
- **Data Quality:** Static summary of the automated data-quality cleaning rules executed during the pipeline phase.
- **Data Explorer:** View and download the filtered curated datasets directly.

## Interactive Filtering
The application features a global sidebar that allows dynamic cross-filtering across all tabs. You can filter by:
- Airline
- Route
- Source / Destination
- Overnight Only
- Anomaly Only

All charts and KPIs immediately recalculate based on your active filters.

## Data Dependency
This application **exclusively consumes the existing curated outputs** generated by the core Python pipeline. It does not run the data engineering rules itself, nor does it load raw data containing sensitive PII.

Ensure the curated files exist in `../data/processed/curated/` before running this app.

## How to Run

1. Navigate to the `streamlit/` directory.
2. Install the necessary dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
